Confidentialité du site vitrine

Mise à jour : 10 octobre 2026

Cette page concerne uniquement le site public ordopro.fr pendant la préparation de la nouvelle application mobile. Le site ne permet ni inscription, ni saisie de données patient, ni achat.

Contact

Pour toute question concernant vos données ou l'exercice de vos droits, écrivez à contact@ordopro.fr. N'envoyez pas de donnée patient par ce canal.

Navigation sur le site

Le site est hébergé par GitHub Pages. GitHub indique enregistrer l'adresse IP des visiteurs à des fins de sécurité. Consultez la documentation de GitHub Pages et la politique de confidentialité de GitHub pour les détails sur ce traitement.

Le code de ce site vitrine ne contient ni formulaire, ni mesure d'audience, ni cookie analytique ajouté par OrdoPro.

Si vous nous écrivez

Le lien de contact ouvre votre logiciel de messagerie. Si vous envoyez un message, nous recevons l'adresse et le contenu que vous choisissez de transmettre afin de pouvoir vous répondre.

Application mobile à venir

Le traitement des données de la future application sera décrit avant son ouverture. Ce site vitrine ne permet pas encore de l'utiliser.
